# lscrp-hud

FiveM HUD resource for LSCRP, based on the existing 0r-hud-v3 resource.

## Installation

1. Place this repository in your server resources as `lscrp-hud`.
2. Start `ox_lib` and `xsound` before this resource.
3. Add `ensure lscrp-hud` to your server configuration.
4. Review `config.lua` for your framework and server settings.

Original author metadata and credits are retained in the resource files.
